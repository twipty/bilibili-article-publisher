### frontmatter 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 否 | 专栏标题；不填则取正文首个 `# 标题`，再退化为文件名 |
| `tags` | 否 | 标签数组，逗号写入 `tags` 表单字段 |
| `category` | 否 | 专栏分类 ID，默认 `0` |
| `original` | 否 | `1` 原创 / `0` 转载，默认 `1` |
| `summary` | 否 | 稿件简介 |
| `dynamic` | 否 | 发布动态文案 |
| `cover` | 否 | 封面图路径，设置后使用单图封面布局 |

> 正文建议从 `##` 开始：`#` 标题会作为文章标题单独提交，脚本默认把 `#` 降级为 `h2` 以避免重复。
